# Achievement Hunter

Brakujące osiągnięcia Steam i sposób, jak je zdobyć — krok po kroku.
Wklejasz tylko link do profilu. Bez logowania do Steam.

## Pobierz

**[Najnowsza wersja → Releases](https://github.com/YoungRedfox/achievement-hunter-releases/releases/latest)**
Plik `AchievementHunter-Setup-<wersja>.exe`. Aplikacja sama informuje o nowych wersjach i aktualizuje się jednym przyciskiem.

## Prywatność

- Profil, klucze i zapisane dane zostają na Twoim komputerze, zaszyfrowane przez Windows.
- Serwer aplikacji tylko przekazuje publiczne zapytania do Steam i tworzy poradniki na podstawie numeru gry i osiągnięcia. Nie zakładamy kont i nie zapisujemy danych o graczach.
